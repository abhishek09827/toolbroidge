6 scenes

Everything an agent loop needs. Nothing it doesn't.

A small canonical tool model with strict provider schemas.

01

One tool definition

Decorate a typed Python function. Pydantic v2 validates arguments and builds the schema.

02

Provider translation

Emits the correct wire shape for OpenAI, Anthropic, or Gemini from the same source.

03

Concurrent execution

Multiple tool calls run through a thread pool and are matched back by tool call id.

04

Streaming reassembly

Partial argument chunks are stitched back into complete tool calls.

05

Structured output retries

Parse or schema errors retry up to three times with the typed error fed back to the model.

06

Explicit refusals

Refusals return immediately as a Refusal object, so you branch on it instead of guessing.

One tool, three wire shapes

What toolbroidge generates for you.

Quickstart

Install, define, run.

# install (provider extras optional)
pip install toolbroidge
pip install "toolbroidge[openai]"
pip install "toolbroidge[anthropic]"
pip install "toolbroidge[gemini]"
from toolbroidge import Agent, tool

@tool("Use when adding two numbers.")
def add(left: int, right: int) -> int:
    return left + right

agent = Agent(provider=provider, tools=[add])
print(agent.run("What is 2 + 3?").output)

Try it with your own key: python3 examples/provider_demo.py --provider anthropic

Structured output, with a safety net

class Answer(BaseModel):
    value: int

agent = Agent(provider=provider, tools=[], output_schema=Answer)
result = agent.run("Return a number")

if isinstance(result.output, Refusal):
    print(result.output.reason)
else:
    print(result.output.value)
